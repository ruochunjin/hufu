# HuFu Benchmarks

Evaluation datasets and loaders for the consistency-checking engine, covering
the datasets used by the HyperMatch and DocChecker papers.  The lab approved
releasing evaluation data with this repository; small datasets are committed
under `data/`, larger ones are fetched on demand.

## Datasets

| Dataset | Task | Size | Source | Status |
|---|---|---|---|---|
| ContraDoc | document self-contradiction | 449 pos / 442 neg | GitHub `ddhruvkr/CONTRADOC` (Apache-2.0) | ✅ committed (`data/ContraDoc.json`) |
| ContractNLI | contract NLI | 10k | HF `kiddothe2b/contract-nli` (LexGLUE dist.) | loader ready |
| DocNLI | document NLI | 900k+ | HF `tasksource/doc-nli` | loader ready |
| ConTRoL | contextual NLI | 8k | HF `tasksource/ConTRoL-nli` | loader ready |
| ECON | evidence conflicts | generated | GitHub `HKUST-KnowComp/EvidenceConflict` | ⚠ data is LLM-generated by their pipeline, not shipped — ingestion deferred |

Remaining Doc4LLM datasets (binary-FEVER-NLI, CaseHOLD, Knowledge Conflict,
binary-MCTest-NLI, MNLI, RTE-Negation, Real-life Contradiction Corpus, RTE-3,
SNLI, StorySumm) can be added to `_HF_DATASETS` in `nli_loaders.py` as needed.

## Usage

```python
import sys; sys.path.insert(0, "benchmarks")
from nli_loaders import load_contradoc, load_hf_nli

# Local, offline:
examples = list(load_contradoc())

# Hugging Face (honors HF_ENDPOINT for mirrors, HF_HUB_OFFLINE=1 for cache):
rows = list(load_hf_nli("contract_nli", split="test", limit=100))
```

Every loader yields `NLIExample(source, example_id, premise, hypothesis,
label, meta)` with label in `{contradiction, entailment, neutral}`.

## Network notes (China mainland)

- Set `HF_ENDPOINT=https://hf-mirror.com` for Hugging Face downloads;
  huggingface.co direct connections time out.
- Set `HF_HUB_OFFLINE=1` once models/datasets are cached — otherwise
  sentence-transformers hangs on hub HEAD probes.
- GitHub (`raw.githubusercontent.com`) is reachable directly.

## Evaluation

Smoke-level evaluation lives in `tests/e2e/test_benchmark_contradoc.py`
(4 sampled contradiction pairs through the reference engine).  Full
paper-number comparison (HyperMatch conflict-detection F1) is tracked as a
follow-up task.
